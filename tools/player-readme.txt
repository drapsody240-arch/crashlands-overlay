CrashLands Overlay {version} (Windows)

1. Run CrashLands-Overlay-Setup-{version}.exe. It installs and starts by itself.
   Windows may show "Windows protected your PC": click More info, then Run anyway.
2. Sign in with Steam when the overlay asks.
3. Launch The Isle and join CrashLands. Press F8 in game for the menu and settings.

The overlay updates itself automatically. To remove it: Windows Settings > Apps > CrashLands Overlay > Uninstall.
